# Дорога к счастью (Road to Happiness)

A browser board-game-style life simulation: live one fantasy life from youth to old age, spend your
limited time on studies, crafts, quests, guild careers, companions and possessions — and die as
happy as you can without being crushed by the burden of it all.

Mechanically inspired by *The Pursuit of Happiness* (Artipia Games, 2015). All content is original.

Status: **playable prototype** — engine, bots, fantasy pack and UI (M0–M5). Run `pnpm dev`. Start with [`AGENTS.md`](AGENTS.md) and
[`docs/ROADMAP.md`](docs/ROADMAP.md).
